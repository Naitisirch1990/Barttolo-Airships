# Barttolo Airships 🚢

Mod experimental e **independiente** para Minecraft Forge **1.20.1**.

**Objetivo:** barco volador construido a partir del schematic aportado por el autor del proyecto, con un piloto y cinco amigos, cuatro inventarios virtuales de 27 espacios, combustible (carbón/lava), llave única, comandos de administración y controles configurables.

⚠️ **ESTADO: Alfa en desarrollo. NO instalar en Barttolo.net ni en mundos importantes hasta superar compilación y pruebas en Minecraft.**

El trabajo se desarrolla primero en una rama separada. Las compilaciones de GitHub Actions son experimentales hasta revisar los registros.

Los repositorios RingWorld y RingWorld-Nether no se modifican.
